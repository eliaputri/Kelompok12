# Tugas-Besar-ETS-PemSpa-Kelompok12
Proyek ini merupakan tugas Pemrograman Spasial (A) yang bertujuan untuk menganalisis indeks spektral dan mengidentifikasi tutupan lahan di Kabupaten Mojokerto menggunakan citra satelit Sentinel-2 Level-2A. Pengolahan data dilakukan menggunakan bahasa pemrograman R melalui RStudio, sedangkan hasil analisis disajikan dalam bentuk peta, statistik zonal, dan WebGIS interaktif.

**Tujuan:**
1. Menghitung indeks spektral NDVI, NDBI, NDWI, dan NDCI.
2. Menentukan nilai ambang (threshold) untuk klasifikasi tutupan lahan.
3. Menganalisis statistik indeks spektral berdasarkan wilayah kecamatan.
4. Menyajikan hasil analisis melalui WebGIS interaktif.

**Data yang Digunakan:**
1. Citra Sentinel-2 Level-2A tanggal 1 Oktober 2026, berupa data reflektansi permukaan.
2. Shapefile (SHP) batas administrasi dari Ina-Geoportal.

**Hasil Analisis**
Berdasarkan hasil klasifikasi komposit, persentase tutupan lahan Kabupaten Mojokerto adalah sebagai berikut:
1. Vegetasi : 69%
2. Bangunan : 25,20%
3. Air : 0,30%
4. Awan : 4,50%
